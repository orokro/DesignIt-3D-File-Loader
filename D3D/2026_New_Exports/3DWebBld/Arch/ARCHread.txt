Release Notes:ARCHAEOLOGY GALLERY FOR MACINTOSH (VERSION 1.1)September 13, 1994Before you install the Archaeology Gallery, please read this file for important installation and usage tips. You may want to print this file before you begin working with your new Gallery, to use as a handy reference.1. WHERE ON MY HARD DRIVE DO I INSTALL THE ARCHAEOLOGY GALLERY?If you have already installed Virtus VR, when the Gallery installation dialog box appears on your screen, we recommend that you locate the Virtus VR folder file name then choose Install. You do have the option of installing the Gallery anywhere you choose. The advantage of installing into the Virtus VR folder is that the new content is merged into already existing folders. For more details, please refer to the Installation card in the Archaeology Gallery box.NOTE FOR VIRTUS WALKTHROUGH PRO USERS: VR Galleries are now compatible with WalkThrough Pro 2.0. You may install the new Gallery anywhere you choose on your hard drive.2. WHAT FOLDERS AND FILES WILL THE ARCHAEOLOGY GALLERY INSTALL ON MY HARD DRIVE?The Archaeology 3-D Galleries, 2-D Galleries and Textures folders will be placed in the original 2-D Galleries, 3-D Galleries, Textures and Bonus Textures folders within the Virtus VR folder if that's where you choose to install the Gallery. The installer will create those folders if you install elsewhere. The Gallery installer will also create an Archaeology Scenes folder.   NOTE FOR VR USERS: All of these folders contain files that Virtus VR needs to operate, so please don’t move or rename the folders or their contents.3. WHAT TEXTURE PALETTES ARE INCLUDED IN THIS GALLERY?ImagesMasonry&WoodStonesOnly the Stones texture palette will be installed directly to the Textures folder within the Virtus VR folder. The Images and Masonry&Wood palettes will be installed into the Bonus Textures folder within the VR folder. If you need to free up memory, move some of the palettes from the Textures folder into another folder (such as the Bonus Textures folder), then restart VR. Keep in mind that the Texture Palettes are available for use only when these are in the Textures folder.The Images palette is provided in an unshaded version only (all of the textures in the palette are paintings and wall reliefs, images that need to be seen clearly). The Masonry&Wood and Stones palettes are provided in shaded versions only.6. HOW CAN I BEST USE THIS GALLERY?You can build your own scenes from scratch by opening a new file and filling it with objects from the 3-D Galleries. You can also use a sample scene as a starting point by opening it and saving the file as another name. Then you can add figures and objects from the 3-D Galleries, modifying shapes and applying textures to add more realism.7.
