Release Notes:SCIENCE FICTION GALLERY FOR MACINTOSH (VERSION 1.1)September 20, 1994Before you install the Science Fiction Gallery, please read this file for important installation and usage tips. You may want to print this file before you begin working with your new Gallery, to use as a handy reference.1. WHERE ON MY HARD DRIVE DO I INSTALL THE SCIENCE FICTION GALLERY?If you have already installed Virtus VR, when the Gallery installation dialog box appears on your screen, we recommend that you locate the Virtus VR folder file name then choose Install. You do have the option of installing the Gallery anywhere you choose. The advantage of installing into the Virtus VR folder is that the new content is merged into already existing folders. For more details, please refer to the Installation card in the Gallery box.NOTE FOR VIRTUS WALKTHROUGH PRO USERS: VR Galleries are now compatible with WalkThrough Pro 2.0. You may install the new Gallery anywhere you choose on your hard drive.2. WHAT FOLDERS AND FILES WILL THE SCIENCE FICTION GALLERY INSTALL ON MY HARD DRIVE?If you choose to install to the Virtus VR folder the Science Fiction 3-D Galleries, 2-D Galleries and Textures folders will be placed in the original 2-D Galleries, 3-D Galleries, Textures and Bonus Textures folders within the Virtus VR folder. The Gallery installer will place a Science Fiction Scenes folder and an Science Fiction Models folder into the Virtus VR folder on your hard drive. If you install elsewhere the installer will create the necessary folders. NOTE FOR VIRTUS VR USERS: All of these folders contain files that Virtus VR needs to operate, so please don’t move or rename the folders or their contents.3. WHAT ARE THE SAMPLE SCENES INCLUDED WITH THE SCIENCE FICTION GALLERY?We have included five Science Fiction sample scenes with this Gallery:Dragonfly Lunar Penitentiary Mirror WorldRushmore 2057Stellar ArkThese scenes are for you to explore and enjoy. If you choose the full install (as opposed to “custom” install) procedure, the scenes will be installed into a Science Fiction Scenes Folder. To get more information on any one of these scenes, including information on the subject and the person who created it, open the appropriate Read Me file in the Science Fiction Scenes folder.4. WHAT TEXTURE PALETTES ARE INCLUDED IN THIS GALLERY?CosmicStone & MetalStone & Metal ShadedSF MixSF Mix ShadedThe Cosmic, SF Mix Shaded and Stone & Metal Shaded palettes will be installed in the Textures folder within the Virtus VR folder. The SF Mix and Stone & Metal palettes (these are the unshaded versions of the shaded palettes) will be installed in the Bonus Textures folder. NOTE: Cosmic only comes in an unshaded version because there is no advantage in shading star fields or celestial bodies. If you need to free up memory, move some of the palettes from the Textures folder into another folder (such as the Bonus Textures folder), then restart VR. Keep in mind that the Texture Palettes are available for use only when these are in the Textures folder.All of the textures in the Science Fiction Gallery palettes are from the first and second Volumes of Form and Function's Wraptures Library of seamless, tileable textures on CD-ROM. The Wraptures Library contains photographic textures in PICT format for use as 3-D texture maps, presentation backgrounds, and graphic source material. You can purchase the Wraptures CD-ROMs through Form and Function's distributor, EDUCORP. That company’s toll-free number is 1-800-843-9497, or you can call 619-536-9999.6.
