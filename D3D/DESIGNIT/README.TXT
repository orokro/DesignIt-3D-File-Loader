DESIGN IT! 3-D Version 1.0
RELEASE NOTES
29 June 1995

Welcome to Design It! 3-D! Before you install the software, 
please read this file for important information. Also, you may want
to print this file for handy reference before you begin working
with Design It! 3-D.

WHAT SHOULD I DO FIRST?

Before you do anything else, please fill out and send in the 
registration card included with Design It! 3-D. Not only will 
we be able to keep you informed about updates to Design It! 3-D 
and other products that work with it, we will also be able to offer 
you better customer support should you need to contact us.

HOW DO I INSTALL DESIGN IT! 3-D?

To install:

1. From File Manager or Program Manager, select Run from the File menu.

2. At the Command Line, type d:\setup\setup

3. Follow the instructions in the dialog box to perform a Full or Custom 
   installation.

Although it is possible to run Design It! 3-D directly off the CD-ROM, 
we strongly recommend that you select the Full Installation and run the 
application from your hard drive. The Full Installation will optimize the 
performance of Design It! 3-D and give you more flexibility in
running the application. 

WHAT DIRECTORIES WILL DESIGN IT! 3-D INSTALL ON MY HARD DRIVE IF I
SELECT THE FULL INSTALLATION?

The Design It! 3-D installer will create a directory on your hard 
disk called DSGNIT3D.  Within this directory, in addition to the Design 
It! 3-D application and this Read Me file, you will find four
sub-directories: 2GALLERY, 3GALLERY, SCENES, MODELS. These directories
contain files which Design It! 3-D needs to operate. Please don't move or
rename them or their contents.

We have included dozens of sample scenes and models with Design It! 3-D.
These scenes and models are for you to explore and enjoy. To get started,
you might want to open one of them and select Play from the Walk menu. This
will take you on a tour through the scene. You can stop the tour at any
point by pressing the mouse button.

WHAT VIDEO MODES WILL DESIGN IT! 3-D RUN IN?

Design It! 3-D will run best with the VGA, SVGA and third-party 256-color
display drivers. However, for the best combination of speed and image
quality, we recommend that you run Design It! 3-D in 256 colors at
640 x 480 screen resolution.

WHAT ARE DESIGN IT! 3-D'S MEMORY REQUIREMENTS?

With simple models, Design It! 3-D will run with as little as 4 MB of
memory. As models grow more complex, Design It! 3-D requires more memory.
For complex models, such as some of those provided in the SCENES directory,
we recommend you have at least 8 MB memory installed on your system.
Windows can use Virtual Memory (using your hard-disk as temporary storage)
but the results are less than desirable. 

If you are running on a machine with 4 megabytes of RAM, we recommend you
use less complex scenes and objects. You can also avoid running other
applications at the same time as Design It! 3-D.

WHAT IS THE MEMORY INDICATOR?

There is a memory indicator to the right of the Message Bar, at the lower
right corner of your screen. The memory indicator contains a colored bar
that shrinks and grows, indicating the amount of memory currently available
to Design It! 3-D. If the bar indicates  that your PC's memory resources
are below 75 percent, the bar is colored blue. When the amount rises above
75 percent, the bar is red.
